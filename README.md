# SpeedCalendar Help

## Preset

### ・All (00-99)

00〜99からランダム出題

### ・Easy (0-27)

00〜27からランダム出題

## Advanced Filter

コマンドは改行または / で区切る

例：all/group1*3/!14

または：
all
group1*3
!14

## 基本構文

### ・数字追加

14 → 14を追加

### ・範囲

0-27 → 0〜27を追加

### ・除外

!14 → 14を削除

### ・重み

group1*3 → group1を3回追加

## ・ショートカット

all → 0-99
cycle1 → 0-27  
cycle2 → 28-55  
cycle3 → 56-83  
cycle4 → 84-99  
doubles →00 11 22 33 44 55 66 77 88 99  

## ルール

- 上から順に処理される
- * は直前の繰り返し
- ! は削除
- / と改行は同じ扱い

## Debug表示（重要）

Advancedモードには「Question Pool Debug」が表示される場合があります。

これは現在の出題候補リストを確認するためのデバッグ機能です。

### ・表示内容

例：

1×49 / 2×50 / 27×5 / 55×12

### ・意味

 「数字×回数」で出題候補の重みを表示しています
　回数が多いほど出やすいことを意味します

### ・注意

　この表示はデバッグ用です
　出題には影響しません
　ユーザーの成績や統計ではありません
